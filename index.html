Header & Footer Joomax

Komponen header dan footer yang dipakai bersama semua website Joomax. Halaman ini memakainya sendiri: coba hover menu di atas, gulir halaman, dan buka hamburger di kanan.

Pasang di website mana pun

<joomax-header sticky current="home"></joomax-header>

  ...isi halaman...

<joomax-footer></joomax-footer>

<script src="https://designjoomax.github.io/headerfooter/joomax-layout.config.js"></script>
<script src="https://designjoomax.github.io/headerfooter/joomax-layout.js"></script>

current menandai menu yang sedang aktif. Isinya id menu di config (home, workspace, creative, gallery). Tanpa atribut ini, halaman aktif dideteksi otomatis dari URL.

Mengubah menu dan footer

Edit joomax-layout.config.js. Semua link ditulis sekali di blok LINK, lalu dipakai di header dan footer.

nav: [
  { id: "home", label: "Home", href: LINK.home },
  { id: "workspace", label: "Workspace", children: [
    { label: "Jadwal Kerja", desc: "Lihat jadwal kerja tim", href: LINK.kerja }
  ]}
]

href: "#" = link sementara. Item dengan children menjadi dropdown.

Isi berbeda untuk satu website

Definisikan window.JOOMAX_LAYOUT sebelum script. Kalau sudah ada, config pusat tidak menimpanya, jadi muat joomax-layout.js saja.

Warna dan ukuran lewat CSS website

:root{
  --jx-accent:#e60020;        /* aksen mode terang */
  --jx-accent-dark:#ff3d55;   /* aksen mode gelap */
  --jx-font:"Poppins",sans-serif;
  --jx-max:1600px;            /* lebar isi header */
  --jx-footer-max:1180px;     /* lebar isi footer */
}

Atribut: sticky, theme="light|dark" (tanpa ini ikut mode terang/gelap website), current="id".
