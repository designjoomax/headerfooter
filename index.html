Header & Footer Joomax

Komponen header dan footer yang dipakai bersama semua website Joomax. Halaman ini memakainya sendiri: header di atas, footer di bawah.

Pasang di website mana pun

<joomax-header sticky></joomax-header>

  ...isi halaman...

<joomax-footer></joomax-footer>

<script src="https://designjoomax.github.io/headerfooter/joomax-layout.config.js"></script>
<script src="https://designjoomax.github.io/headerfooter/joomax-layout.js"></script>

Ubah menu dan footer untuk semua website sekaligus

Edit joomax-layout.config.js. Link sementara memakai "#", ganti dengan link asli kalau halamannya sudah jadi.

Warna dan ukuran lewat CSS website

:root{
  --jx-accent:#e60020;        /* aksen mode terang */
  --jx-accent-dark:#ff3d55;   /* aksen mode gelap */
  --jx-font:"Poppins",sans-serif;
  --jx-max:1500px;            /* lebar isi header */
  --jx-footer-max:1260px;     /* lebar isi footer */
}

Atribut: <joomax-header sticky theme="light|dark">. Tanpa theme, header ikut mode terang/gelap website.
